One sentence (189 characters) that explains the modern internet to a time traveler from 1800, using only words that already existed in their time: a vast library of letters, books and songs, open from one's parlour in an instant, answering back just as fast. `main.ts` writes exactly that one sentence — a single line, no trailing newline — to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
